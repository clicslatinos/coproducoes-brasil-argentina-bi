# Metodologia

## 1. Origem

O projeto deriva de um Trabalho de Conclusão de Curso em Cinema e Audiovisual da Universidade Estadual de Goiás.

A pesquisa original analisa coproduções cinematográficas entre Brasil e Argentina no período de 2012 a 2021.

## 2. Abordagem

A pesquisa combinou:

- pesquisa bibliográfica;
- levantamento de dados;
- análise comparativa;
- entrevistas;
- pesquisa de classificação de gêneros;
- levantamento de disponibilidade em plataformas.

## 3. Dados

Os dados foram extraídos principalmente de ANCINE/OCA e INCAA.

A pesquisa também utilizou bases complementares para gêneros, circulação e disponibilidade.

## 4. Entrevistas

Foram incorporadas entrevistas com três produtoras brasileiras com experiência de coprodução com a Argentina:

- Sombumbo Filmes;
- Sancho y Punta;
- Taiga Filmes.

As entrevistas funcionam como evidência qualitativa complementar aos dados quantitativos.

## 5. Transformação para BI

A transformação para dashboard envolveu:

1. identificação das variáveis relevantes;
2. separação das bases por tema;
3. organização de indicadores;
4. criação de visualizações;
5. construção de narrativa;
6. documentação das fontes;
7. registro das limitações.

O objetivo não foi reconstruir o TCC, mas criar uma camada analítica sobre os dados já levantados.

## 6. Recorte de plataformas

Embora o corpus seja 2012–2021, a disponibilidade digital foi observada em setembro de 2023.

Esse recorte deve permanecer explícito em qualquer reutilização dos dados.

## 7. Interpretação

Os indicadores são descritivos. O projeto busca identificar padrões e relações, mas não utiliza os dados para afirmar causalidade estatística.

## 8. Rastreabilidade

Cada conjunto de dados deve ser interpretado junto de:

- sua fonte;
- seu período;
- seu recorte;
- sua definição;
- suas limitações.

Essa documentação é parte do próprio projeto de BI.
