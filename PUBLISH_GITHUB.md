# Publicação no GitHub

## Nome sugerido do repositório

`coproducoes-brasil-argentina-bi`

## Descrição

Case de análise de dados e Business Intelligence sobre coproduções cinematográficas Brasil–Argentina (2012–2021).

## Estrutura

- `README.md` — apresentação e documentação principal do projeto
- `dashboard/` — dashboard editável em Excel
- `presentation/` — apresentação executiva do case
- `documentation/` — metodologia, dicionário de dados e project card

## Antes de publicar

1. Criar um repositório chamado `coproducoes-brasil-argentina-bi`.
2. Enviar o conteúdo desta pasta diretamente para a raiz do repositório.
3. Conferir se o `README.md` aparece imediatamente na página inicial.
4. Adicionar screenshots do dashboard posteriormente, se desejar.
5. Adicionar o link do GitHub ao currículo e ao LinkedIn.

O currículo e a carta de apresentação não precisam fazer parte deste repositório.
